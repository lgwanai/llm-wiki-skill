> These are not suggestions. Each constraint below was discovered through failure.

- [x] CONSTRAINT: regex char-class byte-fidelity - When editing a regex containing non-ASCII chars (en-dash/em-dash/中文), the Edit tool can mismatch on visually-identical-but-different codepoints (hyphen U+002D vs em-dash U+2014). A bash python-rewrite via base64-safe byte construction corrupted _extract_cited_pages (bad char range `–-~`). Mitigation: verify with `python3 -c "import py_compile; py_compile.compile(..., doraise=True)"` AND a functional call after every regex edit; prefer small targeted Edits over wholesale function rewrites via shell heredocs.

**Do not proceed until the box above is acknowledged.**
